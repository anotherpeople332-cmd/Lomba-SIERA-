# Jelajah Jogja

Situs statis berbasis HTML, CSS, dan JavaScript. Tidak memakai database atau langkah build.

## Publikasi melalui GitHub Pages

1. Push isi folder ini ke branch `main`. Video `assets/video/4k SESUATU DI JOGJA CINEMATIC VIDEO.mp4` tidak ikut diunggah karena ukurannya melebihi batas 100 MB per file GitHub. File tersebut tetap ada di komputer lokal, tetapi video tidak akan tampil pada versi situs yang dipublikasikan.
2. Di repositori, buka **Settings → Pages**, lalu pilih **GitHub Actions** sebagai sumber publikasi.
3. Workflow pada `.github/workflows/pages.yml` akan menerbitkan situs setiap kali ada perubahan di branch `main`. Alamat situs akan muncul di halaman **Settings → Pages** setelah workflow berhasil.

Situs belum dapat dipublikasikan langsung dari folder ini karena folder kerja belum terhubung ke repositori GitHub.
